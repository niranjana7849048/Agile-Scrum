
# Epics and User Stories – Insurance Claims Portal

## Epic 1: Claim Registration

| S.No. | User Story |
|---|---|
| 1 | As a customer, I want to enter my policy details so that I can register an insurance claim. |
| 2 | As a customer, I want to provide incident details so that the insurer understands my claim. |
| 3 | As a customer, I want to submit my claim so that the insurer can begin processing it. |

## Epic 2: Document Upload

| S.No. | User Story |
|---|---|
| 4 | As a customer, I want to upload supporting documents so that I can provide evidence for my claim. |
| 5 | As a customer, I want to view my uploaded documents so that I can verify the files submitted. |
| 6 | As a customer, I want to replace an incorrect document so that I can submit the correct evidence. |

## Epic 3: Claim Tracking

| S.No. | User Story |
|---|---|
| 7 | As a customer, I want to view my claim status so that I know the progress of my claim. |
| 8 | As a customer, I want to view the reason for a pending claim so that I understand what action is required. |
| 9 | As a customer, I want to view the claim decision so that I know whether my claim is approved or rejected. |

## Epic 4: Settlement Notifications

| S.No. | User Story |
|---|---|
| 10 | As a customer, I want to receive a notification when my claim is approved so that I know the decision. |
| 11 | As a customer, I want to receive settlement details so that I know the approved settlement amount. |
| 12 | As a customer, I want to receive a notification when my settlement is processed so that I know when payment is completed. |
