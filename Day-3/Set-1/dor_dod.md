
# Definition of Ready and Definition of Done
## Online Grocery Delivery Application

## 1. Definition of Ready (DoR)

A user story is ready for development when:

1. The story has a clear title and description.
2. Acceptance criteria are defined.
3. The story provides customer value.
4. Dependencies are identified.
5. The story is estimated using story points.
6. The team understands the requirements.

## 2. Definition of Done (DoD)

A user story is considered complete when:

1. Development is completed.
2. Code is reviewed.
3. Unit testing is completed.
4. Acceptance criteria are satisfied.
5. No critical bugs remain.
6. The feature is tested successfully.
7. The story is marked as Done in Jira.

## Conclusion

DoR ensures that a user story is ready to begin development. DoD ensures that the completed story meets the required quality standards.
