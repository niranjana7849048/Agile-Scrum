## MoSCoW Method

- **Must Have:** Essential features required for the application.
- **Should Have:** Important features that can be implemented after essential features.
- **Could Have:** Useful features that can be added if time permits.
- **Won't Have:** Features excluded from the current release.

## Fibonacci Story Point Scale

| Points | Meaning |
|---:|---|
| 1 | Very simple task |
| 2 | Small task |
| 3 | Moderate task |
| 5 | Medium complexity |
| 8 | High complexity |
| 13 | Very high complexity |

## Reference Story

**Reference Story:** Browse Grocery Categories

**Estimated Points:** 3

**Justification:** This story is selected as the reference because it involves displaying grocery categories with moderate development effort. Other stories are estimated by comparing their complexity and effort with this story.

## Estimation Technique

Planning Poker is used to estimate story points. Each team member independently selects a Fibonacci point value. The team discusses differences and agrees on a final estimate.
