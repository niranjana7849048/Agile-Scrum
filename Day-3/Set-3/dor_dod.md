
# Definition of Ready and Definition of Done
## Hospital Appointment Booking Application

## 1. Definition of Ready (DoR)

A user story is Ready when:

- [ ] The user story follows the As a / I want / so that format.
- [ ] The requirement is clearly described.
- [ ] Acceptance criteria are defined.
- [ ] The story provides business or customer value.
- [ ] Dependencies are identified.
- [ ] The story is small enough to complete within a Sprint.
- [ ] The story can be estimated by the Developers.

## 2. Definition of Done (DoD)

A user story is Done when:

- [ ] Development is completed.
- [ ] Code follows the team's coding standards.
- [ ] Unit testing is completed successfully.
- [ ] Integration testing is completed where applicable.
- [ ] Acceptance criteria are satisfied.
- [ ] No critical or major defects remain.
- [ ] Code review is completed.
- [ ] The feature is documented where necessary.

## 3. Conclusion

The Definition of Ready ensures that user stories are sufficiently prepared before entering a Sprint. The Definition of Done ensures that completed features meet the team's quality standards and acceptance criteria.
