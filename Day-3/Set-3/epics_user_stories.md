
# Epics and User Stories – Hospital Appointment Booking Application

## Epic 1: Booking

**Story 1 – View Available Doctors**

As a patient, I want to view available doctors so that I can choose a suitable doctor.

**Story 2 – View Doctor Details**

As a patient, I want to view doctor details so that I can understand the doctor's speciality and availability.

**Story 3 – Book an Appointment**

As a patient, I want to book an available appointment slot so that I can consult a doctor.

## Epic 2: Rescheduling and Cancellation

**Story 4 – View Booked Appointments**

As a patient, I want to view my booked appointments so that I can manage my schedule.

**Story 5 – Reschedule an Appointment**

As a patient, I want to reschedule my appointment so that I can choose another available time.

**Story 6 – Cancel an Appointment**

As a patient, I want to cancel my appointment so that the appointment slot becomes available to others.

## Epic 3: Reminders

**Story 7 – Receive Appointment Confirmation**

As a patient, I want to receive an appointment confirmation so that I know my booking was successful.

**Story 8 – Receive Appointment Reminder**

As a patient, I want to receive a reminder before my appointment so that I do not miss it.

**Story 9 – Receive Rescheduling Notification**

As a patient, I want to receive a notification when my appointment is rescheduled so that I know the updated schedule.

## Epic 4: Doctor Schedule Management

**Story 10 – View Doctor Schedule**

As a doctor, I want to view my appointment schedule so that I can plan my consultations.

**Story 11 – Update Doctor Availability**

As a doctor, I want to update my available time slots so that patients can book suitable appointments.

**Story 12 – Block Unavailable Slots**

As a doctor, I want to block unavailable time slots so that patients cannot book appointments during those periods.

## Summary

- Total Epics: 4
- Total User Stories: 12
- Stories follow the As a / I want / so that format.
