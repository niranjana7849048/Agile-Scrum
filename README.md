# Day 4 – Doing Scrum – Sprint Simulation

This assignment covers practical Scrum sprint execution through three application scenarios.

## Set 1 – Digital Wallet Application
- Average velocity calculation and sprint planning
- Sprint backlog and measurable Sprint Goal
- Task breakdown with hour estimates
- Daily stand-up updates and impediment tracking
- Backlog reprioritisation after a mid-sprint change
- Sprint burndown chart and trend interpretation
- Sprint retrospective and action items
- Definition of Done and build pipeline mapping

## Set 2 – Airline Web Check-in
- Team capacity calculation and sprint planning
- Sprint Goal and Definition of Ready checklist
- Blocked dependency and impediment management
- Backlog refinement and story splitting
- Sprint Review agenda and demonstration script
- Asynchronous stand-up for distributed teams
- Comparison of asynchronous and live stand-ups

## Set 3 – E-Learning Platform
- Sprint planning using team velocity
- Mid-sprint scope change impact analysis
- Daily stand-up and impediment resolution
- Sprint velocity calculation and partial work handling
- Start–Stop–Continue retrospective
- SMART action items
- Automation supporting Definition of Done

## Tools and Concepts
- Scrum
- Sprint Planning
- Sprint Backlog
- Daily Scrum
- Sprint Review
- Sprint Retrospective
- Velocity
- Burndown Chart
- Definition of Ready (DoR)
- Definition of Done (DoD)
- Backlog Refinement
- CI/CD Pipeline
- Markdown

## Conclusion

All three scenarios demonstrate practical Scrum sprint execution, including planning, task management, impediment removal, scope change handling, progress tracking, stakeholder feedback, retrospectives, and software quality practices.
